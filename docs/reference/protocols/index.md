# Protocols

- [Client](client) - The NATS client protocol is used to communicate between the NATS server and clients.
- [Route](route) - The NATS route protocol is used to form a cluster of NATS servers.
- [Leafnode](leafnode) - The NATS leafnode protocol is used to create lightweight, unidirectional connections from edge servers to a central cluster.
- [Gateway](gateway) - The NATS gateway protocol is used to connect multiple NATS clusters together.
