Welcome to NATS Documentation

Welcome to the official documentation for NATS - a simple, secure and high-performance open source messaging system for cloud native applications, IoT messaging, and microservices architectures.

Why NATS?​

NATS is a connective technology built for the ever increasingly hyper-connected world. It is a single technology that enables applications to securely communicate across any combination of cloud vendors, on-premise, edge, web and mobile devices.

Key Features​

  • Ultra-High Performance - NATS can process millions of messages per second
  • Lightweight - Small footprint, minimal overhead
  • Simple to Use - Easy to understand API, no complex configuration required
  • Resilient - Built-in resilience with clustering and fault tolerance
  • Secure - TLS, authentication, and authorization built-in
  • Multi-tenancy - Isolated environments through accounts and users
  • Global Scale - Designed to scale from edge devices to global infrastructure

Core Capabilities​

🚀 Messaging Patterns​

  • Publish-Subscribe - One-to-many communication
  • Request-Reply - Synchronous communication patterns
  • Queue Groups - Load balanced message distribution

📦 Built-in Persistence​

  • JetStream - Distributed persistence layer
  • Key-Value Store - Distributed key-value storage
  • Object Store - Distributed object/blob storage

🌍 Deployment Flexibility​

  • Cloud Native - Kubernetes ready with official Helm charts
  • Edge Computing - Lightweight enough for IoT and edge devices
  • Multi-cloud - Connect across any cloud provider
  • On-premise - Deploy in your own data centers
