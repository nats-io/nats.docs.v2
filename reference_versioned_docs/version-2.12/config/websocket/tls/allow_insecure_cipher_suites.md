# allow_insecure_cipher_suites

<Since version="2.12" />
<Reloadable state="reloadable" />
Permit cipher suites Go considers insecure to be named in
`cipher_suites`. Without it those names are rejected.


## Types

| Type | Description | Choices |
| :--- | :---------- | :------ |
| `boolean` | - | `true`, `false` |
