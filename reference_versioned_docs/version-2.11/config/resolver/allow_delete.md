# allow_delete

<Reloadable /> 
If true, allows JWTs to be deleted. Note, in `full` mode, this will
result in the JWT file being renamed to with a `.delete` suffix, unless
`hard_delete` is true.


## Types

| Type | Description | Choices |
| :--- | :---------- | :------ |
| `boolean` | - | `true`, `false` |
